🌿 Landing Page UMKM Spring View
SPRING VIEW – Citra Maja City  
Dari Warga, Untuk Warga, Tumbuh Bersama.
Landing page HTML mandiri untuk memperkenalkan direktori UMKM dan usaha warga Cluster Spring View. Proyek ini berfokus pada informasi usaha, kontak WhatsApp, dan pendaftaran UMKM warga—bukan penjualan properti dan bukan marketplace.
📦 Isi Paket
`Landing_Page_UMKM_Spring_View.html` — halaman website lengkap dengan styling CSS.
`Banner_Spring_View_Tanpa_Teks.jpg` — banner visual kawasan Spring View.
`README.md` — dokumentasi proyek.
`PETUNJUK.txt` — petunjuk singkat penggunaan.
✨ Fitur
Tema warna hijau dan krem yang mengikuti identitas visual Spring View.
Tata letak responsif untuk desktop dan perangkat mobile.
Direktori 13 usaha warga dengan kategori, deskripsi, nama kontak, dan nomor WhatsApp.
Tombol WhatsApp untuk menghubungi masing-masing usaha.
Tombol pendaftaran menuju Formulir UMKM Spring View.
Bagian ajakan mendukung usaha warga dan footer komunitas.
Tidak memerlukan JavaScript untuk tampilan dasar halaman.
🚀 Cara Membuka
Unduh dan ekstrak file ZIP.
Simpan file HTML dan banner dalam folder yang sama.
Buka `Landing_Page_UMKM_Spring_View.html` dengan klik dua kali menggunakan browser seperti Google Chrome, Microsoft Edge, atau Firefox.
Uji tombol pendaftaran dan tombol WhatsApp satu per satu.
> Jika banner tidak tampil, pastikan file banner berada di folder yang sama dengan file HTML dan nama file tidak diubah.
